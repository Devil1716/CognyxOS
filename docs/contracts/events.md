# Event system specification

## Architecture and lifecycle

CognyxOS uses an in-process durable event log behind the `EventBus` contract. Events are immutable facts, not commands. A publisher validates an event, appends it atomically to the local event store, then dispatches to subscribers. Delivery is **at-least-once**; consumers MUST be idempotent using `event_id`. Ordering is guaranteed only per `aggregate_id` (when present), not globally.

Lifecycle: `created → validated → persisted → dispatched → acknowledged | retried → dead_lettered`. A transient dispatch error uses bounded exponential backoff; permanent validation errors are rejected before persistence. A subscriber can replay from a cursor (`event_id` or timestamp), with the original event and a replay marker. Replayed events MUST NOT trigger externally destructive effects without explicit policy.

## Schema and subscriptions

The event envelope is [event-envelope.json](../../schemas/events/v1/event-envelope.json). Fields include `event_id`, `event_type`, `event_version`, base metadata, optional `aggregate_id`, `priority`, payload, and `replay`.

Subscriptions are durable or ephemeral. A filter contains type prefixes, classification ceiling, aggregate IDs, and optional payload predicates validated by the registry. Subscribers receive only permissions-authorized classifications. Priorities: `critical`, `high`, `normal`, `low`; priority influences dispatch but never bypasses authorization. Default retention is 30 days, audit/security events 365 days, and user-configured retention follows local policy. Compaction is prohibited for audit events.

Event versions use SemVer-compatible additive evolution. Consumers MUST ignore unknown fields; breaking payload changes publish `event_version` major + a new schema. Event IDs are never reused.

## Standard catalog

All rows use `event_id` generated by the envelope, publisher identity from the service registry, and at-least-once recovery. `User` below means the local profile notification/audit subscriber.

| Type                               | Payload required fields                    | Publisher            | Subscribers          | Security / recovery                         |
| ---------------------------------- | ------------------------------------------ | -------------------- | -------------------- | ------------------------------------------- |
| `org.cognyx.application.started`   | `application_id`, `instance_id`, `version` | app host             | registry, audit      | internal; replay rebuilds state             |
| `org.cognyx.application.stopped`   | `application_id`, `instance_id`, `reason`  | app host             | registry, audit      | internal; replay closes state               |
| `org.cognyx.window.opened`         | `window_id`, `application_id`              | window adapter       | UI, audit            | internal; no raw window handle              |
| `org.cognyx.window.closed`         | `window_id`, `reason`                      | window adapter       | UI, audit            | internal; idempotent close                  |
| `org.cognyx.agent.started`         | `agent_id`, `run_id`, `goal_id`            | agent host           | observer, audit      | sensitive; restore run state                |
| `org.cognyx.agent.finished`        | `agent_id`, `run_id`, `outcome`            | agent host           | planner, audit       | sensitive; terminal event immutable         |
| `org.cognyx.task.created`          | `task_id`, `goal_id`, `kind`, `priority`   | planner              | scheduler, observer  | sensitive; replay rehydrates graph          |
| `org.cognyx.task.completed`        | `task_id`, `outcome`, `result_ref`         | executor             | planner, observer    | sensitive; result is reference, not secret  |
| `org.cognyx.tool.executed`         | `tool_id`, `invocation_id`, `outcome`      | tool host            | audit, observer      | restricted; replay never re-executes        |
| `org.cognyx.permission.requested`  | `request_id`, `capability`, `risk_level`   | permission broker    | approval UI, audit   | restricted; replay restores pending request |
| `org.cognyx.notification.created`  | `notification_id`, `category`, `title`     | notification service | UI                   | internal; payload excludes secrets          |
| `org.cognyx.voice_session.started` | `session_id`, `mode`                       | speech service       | UI, audit            | sensitive; never contains audio             |
| `org.cognyx.voice_session.ended`   | `session_id`, `reason`                     | speech service       | UI, audit            | sensitive; idempotent terminal event        |
| `org.cognyx.memory.updated`        | `memory_id`, `operation`, `revision`       | memory service       | indexer, audit       | restricted; replay applies revision only    |
| `org.cognyx.model.loaded`          | `provider_id`, `model_id`, `instance_id`   | model provider       | scheduler, audit     | internal; replay rehydrates inventory       |
| `org.cognyx.model.unloaded`        | `provider_id`, `model_id`, `reason`        | model provider       | scheduler, audit     | internal; idempotent unload state           |
| `org.cognyx.system.booted`         | `boot_id`, `platform`, `version`           | runtime host         | registry, audit      | restricted; starts recovery sequence        |
| `org.cognyx.system.shutdown`       | `shutdown_id`, `reason`, `deadline`        | runtime host         | all managed services | restricted; replay records only             |

Each payload is an object and MAY add fields only under the evolution policy. Publishers MUST document classification, retention override, and payload schema location in the event registry before emission.
